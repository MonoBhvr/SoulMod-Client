- 문자열: `언어파일들/chapterN_windows/lang/lang_ja.json`. `date`·빈값·공백값은
  스킵+리포트, 원문 전제조건 없음. ch1 6240개부터 ch5 15780개까지.
- 폰트: `fnt_ja_*` 한국어 서체 교체가 전부. 범위 끝 55203 = 한글 전체 커버.
  `font.register` op + 아틀라스 바이트 해시 검증.
- 스프라이트: 일어 baked 텍스트(`bg_lang_ja_*`, `spr_ja_*`) 교체.
  `sprite.replace` op, 스테이징 PNG 바이트 해시 검증.
- 코드: 자모/조사 헬퍼(`scr_get_josa`, `scr_is_hangul`, `scr_jamo_join`,
  `scr_jamo_split`) + 빈 스텁. ch5만 별개로 `krdub_init`(260 instr, 더빙
  초기화) + `____struct___654..677` 스텁 24개를 추가한다. 실행 op로 내보내지
  않고 `review.json` ManualReviewRequired로만 기록한다.
- 오디오: ch1~4·런처는 배열이 비어서 이름 리포트만 있다. ch5 1건은 이름+해시+
  스테이지드 WAV 포인터가 있지만 바이트는 패키트에 동봉된 경우에만 쓸 수
  있어서 리뷰 전용으로 기록한다. ch3 더빙 2건(`snd_its_tv_time_kr` 등)과 ch4
  음성 16건도 이름뿐이라 동일 처리.
- 텍스처 페이지 리포트: 폰트/스프라이트 아틀라스 재빌드 부산물. 새 클라이언트는
  아틀라스를 만지지 않으므로 op로 만들지 않는다. ch3 `vid` MP4도 외부 파일이라
  op 대상이 아니다.

재현: `cli.py dtkr-build <lang|NONE> <result.json> <stage> <mod> <game> <out>`
6건 전부 `DTKR-BUILD OK` + 에셋 sha256 대조 + op-type 스캔 통과. DTKR 원본
에셋은 레포에 넣지 않고 로컬에서만 빌드한다.
